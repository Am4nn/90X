# 90x Part 5: Coach — Plan

**Goal:** A personal coach per user that knows their progress and memory, looks things up with tools, reviews pasted solutions, teaches patterns from our own problem bank, runs text mock interviews, keeps a STAR story bank, and writes a Sunday weekly review.

**Spec:** `.planning/SPEC.md` §3 (Coach rows, Privacy, Coach isolation, AI budget), §6.8 tools, §6.9 solution review, §6.10 memory, §6.11 pattern lessons, §7 visuals (mockups `.planning/mockups/desktop-feed-library-coach-me.html` and `mobile-feed-library-coach-me.html`, Coach frames).

## Decisions (2026-09-28, binding)

- **Model:** DeepSeek Pro for coach chat, solution review, lessons, mocks, weekly review (`coachModel()` in `web/src/lib/coach/model.ts` — falls back to Flash when the month's $10 group budget is spent). DeepSeek Pro may keep thinking on. Short structured side-calls (extraction, scoring helpers) use `fastModel()` with `providerOptions: NO_THINKING` (from `@/lib/ai`).
- **Memory backend:** our own `coach_memory` table (no Zep/Letta now). Foundation already built: `web/src/lib/coach/memory.ts` → `listMemory`, `memoryForPrompt`, `extractMemory(userId, { kind, id }, material)`, `ageMemory`.
- **Mocks:** design + behavioral, text only, with timer and stage prompts; STAR story bank feeds behavioral mocks.
- **Weekly review:** included; Sunday; coach's own read shown beside the readiness dial on Me; suggested template changes need Accept.
- **Isolation:** every query is scoped to the signed-in user's id. Friends' data only through `get_friend_summary` (public stats: readiness, streak, solved this week, mock scores).

## Foundation (done by the lead, on `main`)

- Schema (migration `20260928000010_coach.sql`): `coach_threads (kind chat|lesson|review|mock, ref, memory_extracted_at)`, `coach_messages (role user|assistant, parts jsonb, citations jsonb)`, `coach_memory`, `solution_reviews`, `stories`, `mocks` (public score) + `mock_details` (private), `weekly_reviews`. Owner-only RLS; friends read `mocks`.
- `web/src/lib/coach/model.ts`: `coachModel()`, `trackCoachUsage(userId, route, model, usage)`, `modelName`.
- `web/src/lib/coach/memory.ts` + `memory-rules.ts` (tested; `bun run check:coach` exercises it against the real model).
- `web/src/lib/coach/mode.ts`: the **Mode** contract (`CoachKind`, `ModeContext`, `Mode { kind, system(ctx), tools?(ctx), maxSteps? }`, `registerMode`, `modeFor`). Each mode lives in `web/src/lib/coach/modes/<kind>.ts` and is imported once from `modes/index.ts`.
- Knowledge search: Upstash Vector index (built-in embeddings, `query-data` REST with `UPSTASH_VECTOR_REST_URL` / `UPSTASH_VECTOR_REST_TOKEN`; each vector's metadata has `kind` (doc|problem), `title`, `url`, `topic`, `source`, and `data` is the chunk text).
